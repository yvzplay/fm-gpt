# FM-GPT - Football Manager Simulation Game

A detailed web-based Football Manager style game for managing professional football teams. Works locally on your PC.

## Features

### Phase 1: Turkish Super Lig (Süper Lig)
- **Top 10 Teams**: Fenerbahçe, Galatasaray, Beşiktaş, Trabzonspor, Başakşehir, Adana Demirspor, Karagümrük, Alanyaspor, Gaziantep FK, Pendikspor
- **Detailed Squad Management**
  - Player profiles (age, nationality, position, attributes)
  - Contract management
  - Player development & training
  - Injury system

- **Tactical System**
  - Formation selection
  - Set pieces configuration
  - Player instructions & roles
  - Match tactics & adjustments

- **Transfer Market**
  - Buy/Sell players
  - Loan deals
  - Contract negotiations
  - Player valuations

- **Season Management**
  - Match scheduling & results
  - League standings
  - Cup competitions
  - Financial system (salaries, revenue)

- **Match Simulation**
  - Advanced simulation engine
  - Key events (goals, injuries, red cards)
  - Post-match analysis
  - Performance tracking

## Tech Stack

- **Frontend**: React/Vue.js for UI
- **Backend**: Node.js/Python for game engine
- **Database**: SQLite/PostgreSQL for local data persistence
- **Simulation**: Custom game engine

## Installation

```bash
git clone https://github.com/yvzplay/fm-gpt.git
cd fm-gpt
npm install
npm start
```
